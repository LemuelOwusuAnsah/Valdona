# Valdona

A client-side password generator.

## Stack

- Astro 5
- TypeScript (strict)
- Deployed to GitHub Pages and Cloudflare Pages

## Live

https://lemuelowusuansah.github.io/Valdona/

## Development

    npm install
    npm run dev

Local dev: http://localhost:4321/Valdona/

## Build

    npm run build

Output: dist/
